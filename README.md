# Учет начислений и платежей по квартирам

Веб-приложение для ведения учета по квартирам: хранения начальных сальдо, начислений и платежей, а также формирования отчетов по данным PostgreSQL.

## Возможности

- Ведение сальдо, начислений и платежей через веб-интерфейс.
- Расчет исходящего сальдо по формуле: входящее сальдо + начисления − платежи.
- Согласование сальдо между сохраненными периодами одной квартиры.
- Формирование годовой оборотной ведомости, отчета по квартире и сводки должников на выбранную дату.
- Импорт банковских выписок Excel (`.xlsx`): просмотр и редактирование распознанных операций до загрузки.
- Просмотр и обработка строк импорта, которые требуют исправления.

## Технологии

- Java 17 и Spring Boot
- Spring MVC, Thymeleaf, Spring Data JPA
- PostgreSQL 17
- Apache POI для чтения Excel
- Maven

## Требования

- JDK 17 или новее
- Maven
- Docker и Docker Compose для запуска PostgreSQL из конфигурации проекта

## Запуск

1. Запустите PostgreSQL:

   ```bash
   docker compose up -d
   ```

   Compose-файл публикует PostgreSQL на порту `5433` хоста. Параметры подключения по умолчанию заданы в `docker-compose.yml` и `src/main/resources/application.properties`.

2. Запустите приложение из корня проекта:

   ```bash
   mvn spring-boot:run
   ```

3. Откройте приложение: <http://localhost:8080>.

Чтобы собрать исполняемый JAR:

```bash
mvn package
java -jar target/accounting-lab3-1.0.0.jar
```

При запуске приложение создает необходимую схему PostgreSQL. Данные не заполняются автоматически: их можно внести вручную или импортировать из выписки.

## Настройка подключения

Подключение и параметры запуска можно переопределить переменными окружения:

| Переменная | Назначение |
| --- | --- |
| `DB_URL` | JDBC URL PostgreSQL |
| `DB_USER` | Пользователь базы данных |
| `DB_PASSWORD` | Пароль базы данных |
| `PORT` | Порт веб-приложения |
| `APP_TIME_ZONE` | Часовой пояс приложения |

Например, для локальной базы на стандартном порту PostgreSQL:

```bash
DB_URL=jdbc:postgresql://localhost:5432/lab3 mvn spring-boot:run
```

## Разделы приложения

| Раздел | Адрес |
| --- | --- |
| Сальдо | `/data/saldo` |
| Начисления | `/data/charges` |
| Платежи | `/data/payments` |
| Импорт выписки | `/data/import` |
| Строки импорта, требующие исправления | `/data/import/errors` |
| Оборотная ведомость | `/reports/turnover` |
| Отчет по квартире | `/reports/apartment` |
| Сводка должников | `/reports/debtors` |

## Структура проекта

- `src/main/java` — контроллеры, сервисы, модели и доступ к данным.
- `src/main/resources/templates` — HTML-шаблоны страниц.
- `src/main/resources/schema.sql` — структура базы данных и функции отчетов.
- `src/test/java` — автоматические тесты.
